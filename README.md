# My Budget Tracker

This project is the Week 2 foundation for a personal budget and expense tracker built with plain HTML and CSS.

## What is included

- **Page header:** Displays the tracker title, description, and a small budget-themed logo.
- **Add Expense form:** Includes labeled name, amount, category, and date controls. The category uses a five-option dropdown, and the button is ready for future JavaScript functionality.
- **Expense table:** Shows five sample expenses using a semantic `table`, `thead`, `tbody`, `tr`, `th`, and `td` structure.
- **Interactive help:** A collapsible `details` section explains how the tracker will work.
- **Multimedia:** Includes an image logo and an embedded budgeting tips video.
- **CSS styling:** Uses element, class, ID, descendant, direct-child, pseudo-class, negation, focus, and hover selectors to style the interface.

## Running the project

Open `index.html` in a web browser. The page does not require a build tool or server yet.
